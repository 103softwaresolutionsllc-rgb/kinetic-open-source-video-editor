# Security

Kinetic processes media in the browser with FFmpeg.wasm. Please report vulnerabilities privately instead of filing a public issue when the report could put users at risk.

## Report

Email **103softwaresolutionsllc@gmail.com** with:

- A description of the issue
- Steps to reproduce
- Impact (for example: another visitor could recover media)

## Scope

In scope: this repository and the deployed static Kinetic web app.

Out of scope: third-party CDNs used to load FFmpeg.wasm, and files a user chose to download to their own device.
